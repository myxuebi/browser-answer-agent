## Name

Answer Agent

## Short Description

Analyze webpage HTML with your own AI model, preview answers, select options, fill fields, and continue to the next question.

## Description

Answer Agent is a webpage practice assistant that connects to an AI model service of your choice. Start a task to analyze the current page's HTML and element information, preview suggested answers, or automate answer selection and text input.

Features:

- Configure your own API endpoint, model name, and API key.
- Connect to Chat Completions or OpenAI Responses services, including compatible local services.
- Choose supported reasoning effort levels and optionally enable image input or Responses reasoning summaries.
- Preview suggested answers and explanations before applying selected suggestions.
- Select answer options and fill supported text fields, textareas, and rich-text input areas.
- Continue to the next question or page. The extension verifies new-question text before answering again instead of treating timers as question changes.
- Use a side panel, webpage floating window, or compact translucent dot.
- View execution logs, copy or clear them, and stop a task.
- Use Simplified Chinese or English automatically according to your browser interface language.

You must configure a model service before use. Third-party model services may charge fees. When you start a task, webpage content is sent to the endpoint you configure; optional image support also sends accessible images. API keys are saved locally in the browser profile. See the privacy policy for details.

Model answers can be incorrect. Browser restrictions and website implementations may limit image access and simulated interactions. Use the extension for practice or other authorized activities.
